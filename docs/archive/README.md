# Roadmap milestone archive

This directory contains completed roadmap milestones. Each milestone is stored
in one immutable summary named:

```text
YYYY-MM-DD-short-milestone-name.md
```

The date is the milestone completion date and the short name uses lowercase
kebab-case. An archive preserves the milestone goal, every step with its
completion date and result, and the gates that were passed. `ROADMAP.md` keeps
only a concise completion record linking to this file.

Milestones and individual steps must not be moved here while any milestone step
is incomplete.
