# Инструкции для агентов

- После полного завершения каждой поставленной задачи всегда создавай Git-коммит со всеми относящимися к задаче изменениями.
- Перед коммитом запускай подходящие проверки и `git diff --check`.
- Не включай в коммит посторонние пользовательские изменения.
- При добавлении или изменении бенчмарка всегда указывай в комментарии рядом с
  ним показатели последнего локального запуска и достаточные параметры запуска,
  чтобы результат можно было сравнить с будущими измерениями.
